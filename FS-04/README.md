# FS-04: Multi-Tenant SaaS Project Management Platform

## Overview
A Jira-like multi-tenant SaaS project management platform built with React, TypeScript, Node.js, Express, PostgreSQL, Prisma, and Docker.

## Core Features
- Multi-tenant workspace isolation (`tenant_id`) with role-based permissions
- REST API with workspace, project, board, issue, and sprint models
- Drag-and-drop Kanban board UI in React
- Custom workflows, comments, attachments, and audit logs
- Stripe subscription billing integration and CI/CD deployment pipeline
