# FS-01: Multi-Vendor E-Commerce Marketplace

## Overview
An Amazon-style multi-vendor e-commerce platform built with React, TypeScript, Node.js, Express, PostgreSQL, Prisma, and Tailwind CSS.

## Core Features
- Role-based authentication (Customer, Vendor, Admin) using JWT
- Vendor onboarding, product CRUD, and search/filtering
- Shopping cart, checkout, and order lifecycle tracking
- Split payments and platform commission calculation
- Admin analytics dashboard and PDF invoice generation
